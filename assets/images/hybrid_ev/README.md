# Авторские схемы R17

20 оригинальных SVG в source/ и runtime PNG ×3, созданных tools/render_hybrid_ev_assets.py.
Собственная геометрия и синтетические модели E0–T0/K1–K5, MIT документация проекта.
Общие графические helpers R15 переиспользованы без изменения прежней графики.
Рисунки производителей, логотипы, pinout и сервисные точки не копировались.
Технические принципы/источники: docs/roadmap/R17_MODULE_14_PLAN.md §10.
Каталог хранит только размеры. Числа не нормы производителя и не инструкция сборки.
Нет коммутационных последовательностей, приборов или практических HV-действий.
PNG имеют белый непрозрачный фон. Важные условия повторяются Flutter captions.
Arial используется локально при resvg-рендере; файл шрифта не распространяется.
