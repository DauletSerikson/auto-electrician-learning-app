# Авторские иллюстрации модуля 10

Все 15 композиций созданы для этого проекта как SVG-код агентом Codex
по утверждённому [плану R13.1](../../../docs/roadmap/R13_MODULE_10_PLAN.md).
Чужие изображения, фотографии, CAD и логотипы не использованы. Это схемы
обучения, не монтажные чертежи и не копии изделий определённой марки.

Генератор: `tools/render_wiring_repair_assets.py`, с существующими
примитивами `render_obd_assets.py`. Экспорт: resvg-py 0.2.0 и системный Arial,
логическая ширина 320 px, PNG 3× (960 px), белый непрозрачный фон для обеих
тем. Новых Flutter-зависимостей нет. SVG sources не включаются в APK;
рендерер использует PNG. Для воспроизведения нужен Python с resvg-py
и доступный Arial; изменять pubspec dependencies не требуется.

| Stem | Учебная задача |
| --- | --- |
| `wire_anatomy` | Жила, проволоки и изоляция |
| `strand_area_harness` | Сумма площадей металла, оболочка и клипса |
| `length_area_resistance` | Полный путь W03 с прямым и обратным проводами |
| `connector_anatomy` | Корпус, terminal, фиксация и seal |
| `terminal_and_probe` | Зоны terminal и подходящий адаптер |
| `crimp_criteria` | Названные дефекты: проволока снаружи и изоляция в зоне жилы |
| `splice_strain_relief` | Соединение, защита и разгрузка |
| `protection_layers` | Раздельные задачи защитных слоёв |
| `harness_damage` | Обрыв, перетирание и коррозия как гипотезы |
| `open_localization` | Две фазы C2 и отдельный изолированный Ω-тест |
| `repair_verification` | План восстановления и контроля |
| `headlamp_contact` | C1: потеря плюсового контакта, точки и полярность |
| `wet_ground_connector` | C3: возврат под нагрузкой, отличие OFF |
| `abrasion_isolation` | C4: открытый F и отдельная изолированная ветвь |
| `bad_splice_heating` | C5: локальная мощность до/после ремонта |

Параметры W03/C1–C5 синтетические, около 20 °C. R нагрузок фиксированы
только в учебной рабочей точке; расчёт температуры, яркости, ресурса и
времятоковой характеристики F не выполняется. Часть проводов идеализирована
нулевым R: это явно указано в уроках. Проводники имеют связность только
по показанной схеме; подписи не являются дополнительными электрическими
ветвями. Ω-карты отделены от включённых цепей. Отрицательное показание
при перестановке щупов не является другим дефектом.

Вид обжима показывает критерии подготовки, но не подтверждает высоту,
усилие вырыва, электрическую исправность или квалификацию ремонтника.
Числовые допуски конкретного изделия и метод его контроля задаёт изготовитель.
Процедуры OEM/TE/Molex/ISO не воспроизводятся этими условными разрезами.

Источники принципов и ограничения приведены в §11 плана. Проверки:

[электротехническое ревью](../../../docs/verification/R13_MODULE_10_ELECTRICAL_REVIEW.md).
