# Авторская графика модуля 9

Все схемы и данные созданы для проекта в R12 (2026-10-17), без копирования
сторонних изображений, фотографий, логотипов или сервисных схем автомобиля.
Редактируемые источники — `source/*.svg`, UI использует соответствующие PNG.
Генератор: `tools/render_starting_charging_assets.py`, helpers существующего
`render_obd_assets.py`, resvg-py 0.2.0. Это tooling, зависимости Flutter не добавлены.
Для экспорта нужен доступный Arial и Python с resvg-py; PNG имеет масштаб 3×,
исходный viewBox шириной 320. Существующее локальное tooling можно подключить
через PYTHONPATH; никакие пакеты не устанавливаются в приложение.

| `battery_test_context` | Условия и сравнительные результаты на полюсах |
| `battery_pulse` | Две линейные модели: U от времени при импульсе 100 A |

| `charging_power` | Параллельные потребители, полярность возврата N→G |
| `charging_control` | IBS, ECU, регулятор; сравнение с локальным управлением |

Это условные иллюстрации для обычной 12 V системы с минусом на массе.
Схемы показывают порядок узлов/функций, а не трассировку реального автомобиля.
G и N различаются под током. При стартерном токе возврат G→N, при зарядном —
N→G. Управление отделено пунктиром, силовые пути — сплошные линии.
В `wake_network` стрелки показывают ход события, а не последовательную
силовую цепь блоков. Малый ток управления исключён из числовой S-модели.
Мотор содержит противо-ЭДС, не постоянный резистор. АКБ при импульсе — линейная
модель без динамики химических процессов. C0/C1/C2 — отдельные измеренные
рабочие точки, без предположения постоянной U/I-характеристики АКБ.

Характеристика Fd относится только к учебному элементу при фиксированной
температуре: 0,20 A→2 mV; 0,50 A→5 mV; 0,80 A→8 mV. Она не является
таблицей реального предохранителя. Пределы 10 A/30 s и 3 A длительно —
данные вымышленного прибора, не общие пределы мультиметров.
Все обязательные числа/условия повторяются обычным Flutter-текстом;
подписи внутри PNG не масштабируются textScaler. Белое поле PNG сохраняет
контраст внутри схемы в обеих темах. Реальные captures renderer и ограничения
визуальной проверки описаны в `docs/verification/R12_MODULE_9.md`.
