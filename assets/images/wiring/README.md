# Авторские схемы R8 — модуль 5

Все семь рисунков впервые созданы для этого проекта агентом Codex по заданию
владельца 2026-10-11. Геометрия, компоновка, подписи и учебные топологии
нарисованы программно из SVG-примитивов. Сторонние растровые изображения,
OEM-схемы, логотипы и AI-generated artwork не использованы. Общепринятые
электрические символы перерисованы самостоятельно; страницы источников
использованы для проверки принципов, не как изображения для копирования.
Схемы — обобщённые учебные примеры, не документация конкретного автомобиля.
На авторские исходники/материалы распространяется MIT проекта.

SVG в `source/` — редактируемый исходник. PNG рядом — экспорт ×3 для Flutter
`ImageLessonBlock`. SVG не загружаются приложением и не требуют SVG-package.
Arial используется только при экспорте; файл шрифта в репозиторий не включён.
PNG содержит готовые пиксели, не требует установленного Arial на телефоне.

## Легенда и техническое ревью

- Длинный штрих батареи — плюс, короткий — минус, также явно подписаны +/−.
  Символ с двумя элементами не задаёт число физических ячеек АКБ.
- Лампа: круг с крестом; выключатель: неподвижные контакты и подвижная линия;
  предохранитель: прямоугольник с проходящей линией. Использована привычная
  европейская манера изображения; формальная сертификация IEC/OEM не заявлена.
- В 2B точка означает электрический узел, мостик — пересечение без связи.
  В других документах может быть другая легенда; её надо прочитать.
- Реле K1 переключающее: 30 общий, 87 NO, 87a NC относительно невозбуждённой
  катушки; 86/85 — катушка. Прямоугольник нижнего K1 — электромагнитный привод.
  Пунктир от него до подвижного контакта — механическая, не электрическая связь.
  B1+ и B1− — выводы одного источника. Обе части имеют свою защиту F1/F2.
- D1 — защитный диод параллельно катушке. Катодная черта на стороне 86 (+),
  анод на стороне 85 (−). При штатном питании диод заперт. Рисунки показывают
  установившиеся состояния, не затухание тока после выключения.
- Расположение ножек и функции других реле не выводятся из этого рисунка.
  Особенно нельзя путать 87/87a с двойным 87 и игнорировать защитный диод.
- X1/X2: пунктирная рамка — граница разъёма, соединённые парные терминалы —
  состыкованный контакт (условная схема соединений). Это не рисунок формы
  штекера/гнезда. Локальные номера X1:3/4 и X2:7/8 не обязаны совпадать.
- Переходы: A — лист 1 A3 ↔ лист 2 B4; B — лист 1 C3 ↔ лист 2 C4.
  Координатная сетка страницы опущена, адреса заданы подписями. W1/RD/1,5 мм²
  относятся только к A и локальной легенде, не к любому красному проводу.
- В 5C защёлка сверху с обеих сторон одного учебного корпуса; передняя
  нумерация 1/2/3, 4/5/6 зеркальна задней 3/2/1, 6/5/4. Номер контакта не меняется.
  Это авторский корпус, не универсальная OEM-распиновка. У X2 здесь нет вида корпуса.

Проверка опирается на первичные материалы, просмотренные 2026-10-11:

- [Open University: батарея, лампа и выключатель](https://www.open.edu/openlearn/mod/oucontent/view.php?extra=longdesc_id17&id=68374) — полярность штрихов батареи и формы символов.
- [HELLA: обозначения реле и диод](https://www.hella.co.nz/en/about-us/technology/relays-and-flasher-units/elimating-voltage-spikes/) — 30/85/86/87/87a и необходимость учитывать подавление выброса.
- [HELLA: каталог реле](https://www.hella.com/forvia-us/assets/documents/Relays_Catalogue_2024_EN_LRes.pdf) — разные исполнения и схемы контактов. Рисунки каталога в проект не перенесены.
- [TE Connectivity: AMPLIMITE](https://www.te.com/content/dam/te-com/documents/aerospace-defense-and-marine/aerospace/global/connectors/mil-dtl-24308.pdf) — необходимость различать вид, тип корпуса и обозначение полостей; наш X1 не соответствует конкретному изделию из каталога.

## Экспорт и просмотр

Windows, Python 3.13; внешняя tooling-библиотека `resvg-py==0.2.0` установлена
отдельно от Flutter-проекта, не добавлена в pubspec/dependencies. Пример:

```powershell
python -m pip install --target "$env:TEMP\electrician-r8-svg-tools" resvg-py==0.2.0
$env:PYTHONPATH = "$env:TEMP\electrician-r8-svg-tools"
python tools/render_wiring_assets.py
```

Экспорт изменяет только PNG, SVG остаётся исходником. Используются Arial и
его bold-вариант из системных шрифтов. На иной ОС результат шрифтового
рендеринга может отличаться; перед коммитом PNG снова проверять визуально.

На 360 logical px в `LessonScreen` padding 20 с каждой стороны даёт **320 px**
для изображения. Все SVG имеют viewBox шириной 320: текст минимум 18 px,
штрих 3 px, подписи основных элементов 18 px bold. Экспорт ×3 улучшает
детализацию, но не увеличивает логический размер букв. Сведения о реальной
проверке renderer и preview находятся в `docs/verification/R8_GRAPHIC_PILOT.md`.

Открытые кружки — выводы; отсутствие линии между парой выводов показывает разъединение. Закрашенные точки — электрические соединения и контрольные точки. Обозначения C и G3 в стартере локальные, их нельзя смешивать с C корпуса генератора. Rк обозначает эквивалент сопротивления контакта, не установленный резистор. Схемы не изображают внутреннее устройство ECU, стартера и генератора. Подробные условия ON/OFF, изоляции и измерений задаются соседними текстовыми блоками. Происхождение и связь всех повторений проверяются тестами и отчётом `docs/verification/R9_MODULE_6.md`.
