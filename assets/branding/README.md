# Launcher artwork

`auto_electrician_app_icon.png` — утверждённый владельцем исходник иконки
проекта «Автоэлектрика с нуля» (887×887 px).

По заявлению владельца, изображение сгенерировано специально для проекта
с помощью OpenAI image generation; сторонние исходные изображения и
логотипы не использовались. Это описание происхождения, а не гарантия
исключительных авторских прав на сгенерированное изображение.

Android resources воспроизводятся командой:

```powershell
./tools/generate_launcher_icons.ps1
```

Legacy mipmaps: 48/72/96/144/192 px. Adaptive icon (API 26+) использует
белый background и raster foreground 432×432 px (108 dp at xxxhdpi),
с исходным рисунком в центральных 60 dp. Отступы сохраняют основной рисунок
при круглой и скруглённой квадратной маске. Исходник не перерисовывается.
Фактический вид в launcher необходимо проверить на устройстве в R6.6.
Splash-screen design не изменялся.
