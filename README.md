# Auto Electrician Learning App

Интерактивное Flutter-приложение для последовательного изучения автомобильной электрики с нуля.

Проект создаётся как учебный тренажёр: пользователь не только читает теорию, но и выполняет расчёты, работает с виртуальными электрическими цепями и мультиметром, проводит измерения и решает диагностические задачи.

> Проект находится в активной разработке.

## Цель проекта

Основная цель — создать структурированный интерактивный курс, который помогает перейти от базовых понятий электричества к пониманию автомобильных электрических систем и системной диагностике неисправностей.

Приложение рассчитано в первую очередь на начинающих, которым необходимо последовательно освоить:

- технику безопасности;
- напряжение, ток и сопротивление;
- закон Ома;
- последовательные и параллельные цепи;
- работу с мультиметром;
- измерение напряжения, сопротивления и силы тока;
- поиск обрывов;
- измерение падения напряжения;
- базовую диагностику электрических неисправностей автомобиля.

## Текущее состояние

На текущем этапе реализованы три учебных модуля:

1. **Техника безопасности**
2. **Основы электричества**
3. **Мультиметр**

Всего в текущей версии курса — **22 урока**.

Контент курса хранится отдельно от интерфейса приложения в JSON-файлах, что позволяет расширять курс без жёсткого размещения учебного материала внутри UI-кода.

## Принцип обучения

Уроки строятся вокруг последовательности:

```text
Теория
   ↓
Пример
   ↓
Интерактивное задание
   ↓
Измерение / диагностика
   ↓
Проверка ответа
   ↓
Закрепление материала
```

Основная идея проекта — не превращать обучение автоэлектрике в электронную книгу, а дать пользователю возможность взаимодействовать с изучаемыми системами.

## Интерактивные тренажёры

Проект содержит несколько типов специализированных учебных блоков.

### Электрические цепи

Интерактивная визуализация простых цепей позволяет изучать:

- замкнутую и разомкнутую цепь;
- последовательное соединение;
- параллельное соединение;
- влияние обрыва на работу потребителей.

### Виртуальный мультиметр

Тренажёр знакомит пользователя с:

- режимами мультиметра;
- измерительными разъёмами;
- подключением щупов;
- выбором режима измерения;
- типичными ошибками при подключении.

### Измерения

Отдельные практические блоки моделируют:

- измерение напряжения аккумулятора;
- обратную полярность;
- измерение сопротивления;
- поиск обрыва;
- прозвонку цепи;
- измерение падения напряжения;
- измерение силы тока.

### Диагностика

Диагностические задания предлагают неисправную электрическую цепь, после чего пользователь выполняет измерения и на основании результатов выбирает предполагаемую неисправность.

## Технологии

Проект использует:

- **Flutter**
- **Dart**
- **Material Design**
- **SharedPreferences**
- JSON для хранения структуры учебного курса
- Flutter Test для автоматизированных тестов

Приложение проектируется как offline-first: для прохождения уже установленного курса не требуется сервер или учётная запись.

- базовая целостность метаданных курса.
