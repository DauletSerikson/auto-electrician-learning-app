# v0.1.0 — проект release notes

Версия приложения: **0.1.0+1**. Целевая платформа — **Android**.
Релиз ещё не опубликован: R6.6B остаётся IN PROGRESS, финальный READY
не подтверждён. Этот документ подготовлен для будущего portfolio/sideload релиза.

- 3 модуля, 22 урока: безопасность, основы автомобильной электрики и мультиметр.
- Теория с иллюстрациями, вопросы, расчётные задачи и итоговые проверки.
- Учебные электрические цепи, виртуальный мультиметр, измерение напряжения,
  сопротивления, прозвонки, падения напряжения и силы тока.
- Диагностические кейсы с сохранёнными результатами измерений и выбором диагноза.
- Offline-first: bundled JSON и локальное сохранение завершённых уроков,
  общий прогресс и следующий незавершённый урок. Сервер и учётная запись не нужны.
- Светлая и тёмная темы, собственная launcher icon, MIT license и реальные
  Android screenshots в README.
- Автоматические проверки контента, domain/simulation, storage, widgets,
  navigation и полного app smoke flow. Локальный набор: 600 тестов.

Android applicationId: `com.dauletserikson.autoelectrician`.
Release-mode демонстрационный APK использует **debug signing** для sideload;
это не production-store signing. Google Play distribution не подготовлена.
APK собирается командой `flutter build apk --release` в
`build/app/outputs/flutter-apk/app-release.apk` и не включается в Git.

Ограничения: симуляторы — специализированные учебные модели. Приложение
не заменяет профессиональную диагностику или документацию автомобиля.
Нет облачного восстановления, истории попыток/баллов, unlocking или
сохранения текущей quiz session. iOS, desktop и web не проверены как release targets.
TalkBack не проверен. При удалении приложения/данных локальный прогресс теряется;
прогресс старого development applicationId автоматически не переносится.

CI configured, remote run NOT VERIFIED. Физический smoke частично подтверждён
владельцем; незакрытые проверки перечислены в [R6.6](../verification/R6_6.md).
Дополнительные кадры Voltage Drop, Current Measurement и диагностики пока
отсутствуют. Итоговая проверка перед публикацией остаётся обязательной.
