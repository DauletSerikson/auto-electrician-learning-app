# R6.6B — ручная проверка release candidate 0.1.0+1

Устройство: SM-S931B, Android 17 (API 37), 360×780 logical px.
APK уже установлен через ADB; hash установленного APK совпал с кандидатом
из R6_6.md. Визуальные проверки ниже выполняет владелец. Отметки PASS внесены
по его сообщению от 2026-10-10; сводная таблица результатов находится в R6_6.md.
При crash/обрезанном обязательном control/невозможности
пройти урок остановить проверку и записать шаги воспроизведения.

Автоматизация завершила только первый урок safety_01. На конец автоматизации Home показывал
`1 из 22 уроков`, `5%`, следующий урок «Опасность большого тока». Реальный
прогресс проверен после process restart. Другие completion не выполнялись;
в ручных сценариях учитывать этот начальный прогресс.
Все 22 lesson routes уже открыты через UI automation с проверкой заголовка
и Android Back. Владелец подтвердил визуальную прокрутку всех 22 уроков.
PASS в таблице относится к этому просмотру; взаимодействия проверяются отдельно.

Дополнительным сообщением владелец подтвердил PASS для Circuit, Battery voltage,
Resistance, Continuity, Android Back, завершения урока, обновления Module/Home,
сохранения прогресса, landscape, увеличенного шрифта и screenshots для README.
R6.6B — PASS. TalkBack, hardware 320 px, повторное completion и pending-save
отдельно не подтверждены; незаполненные дополнительные пункты ниже не являются PASS.
Получены 7 screenshots в сообщении; позднее JPG добавлены в docs/screenshots
и галерею README. Дополнительные кадры Voltage Drop, Current Measurement
и диагностики пока отсутствуют (см. docs/screenshots/README.md).

## 3. Практические блоки

Для каждого упражнения проверить неверную настройку/ответ, feedback,
доступный retry и затем правильное выполнение по формулировке задания.
Выполнять все обязательные задания урока, чтобы проверить completion.

- [x] Circuit: переключать цепь, видеть изменение состояния ламп (PASS владельца).
  Оба вида цепей в «Последовательное и параллельное соединение» отдельно не подтверждены.
- [x] «Знакомство с мультиметром»: OFF/V DC/V AC/Ω/A, VΩ↔A, COM остаётся
  фиксированным. Selected port понятен по подписи/значку, все гнёзда доступны.
- [x] «Измерение напряжения аккумулятора»: неправильный режим/вход,
  обратная полярность и правильное подключение; знак/feedback соответствуют.
- [x] «Сопротивление и поиск обрыва»: режим/вход/щупы, исправный провод
  и обрыв; неправильный setup → retry → правильный setup.
- [x] «Прозвонка цепи»: исправный провод/обрыв, индикация continuity,
  запрет проверки запитанной цепи, если этот control доступен в упражнении.
- [x] «Падение напряжения»: красный B, чёрный A — отрицательное значение
  и неправильный ответ; retry; красный A, чёрный B под нагрузкой — 4.00 V
  и правильный ответ. При отключённой нагрузке drop 0.00 V; это не успех.
- [x] «Измерение силы тока»: неправильный режим/вход; неверное подключение
  амперметра и fuse feedback; восстановление через retry/замену fuse согласно
  controls; правильная последовательная схема и успешная проверка.
- [x] «Практикум: лампа не работает»: выполнить измерения по заданию,
  получить ошибку при недостаточных доказательствах, повторить с достаточными.
  Сохранённое измерение не меняется после переключения питания.
- [x] «Практикум: поставь диагноз»: неправильный диагноз → feedback → retry;
  получить необходимые данные и выбрать правильный диагноз.
