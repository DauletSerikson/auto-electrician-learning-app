## Repository hygiene и оставшиеся gates

В текущих tracked files и новых workflow/release/report files проверены
имена keystore/key.properties/local.properties/APK/build artifacts,
типичные сигнатуры private keys/tokens и literal credentials. Совпадений,
указывающих на секреты, не найдено. APK и android/local.properties ignored.
Локальных абсолютных путей к Users/projects/sdk в tracked text не найдено.
Это проверка текущего snapshot по именам/паттернам, не гарантия отсутствия
любых секретов во всей истории Git.

Для окончательного READY требуется закрыть [R6.6B](R6_6.md) владельцем,
проверить CI на GitHub после отдельно разрешённого push и выполнить итоговый
read-only аудит. Непроверенные ручные сценарии и условные проверки перечислены
в [device checklist](R6_6_DEVICE_CHECKLIST.md). Дополнительные screenshots
Voltage Drop, Current Measurement и диагностики пока отсутствуют.

После commit выполняется только предварительный read-only аудит;
его выводы сообщаются владельцу отдельно, без исправлений в ходе аудита.
Push, merge, tag и GitHub Release не выполнялись.
