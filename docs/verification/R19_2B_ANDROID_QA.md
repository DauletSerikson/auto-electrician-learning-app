## TalkBack — ручной чек-лист

**MANUAL QA REQUIRED. Ни один пункт ниже ещё не выполнен.**
Проверка accessibility hierarchy или наличие Semantics в коде не считается
прослушиванием TalkBack. Сейчас недоступны и устройство, и фактический звуковой вывод.

Перед началом владелец должен согласовать/самостоятельно включить TalkBack
и нужные настройки шрифта/темы. Записать исходные настройки и восстановить их
после сеанса. Без разрешения агент настройки не меняет.

Для каждого пункта записать PASS/FAIL, экран, последовательность жестов,
ожидаемое и фактическое объявление; при FAIL — воспроизведение без личных данных.

- [ ] **Home:** последовательным движением фокуса прочитать название, прогресс,
  следующий урок, «Курс» и «Практика диагноста». Действия имеют понятные названия,
  числа модулей/уроков/кейсов различимы; декоративные иконки не мешают чтению.
- [ ] **Список модулей/уроков:** фокус достигает элементов при прокрутке;
  название, доступное действие и отметка завершения понятны; длинные названия
  не теряют важной информации; Back возвращает в ожидаемое место.
- [ ] **Quiz:** прочитать вопрос и варианты, выбрать ответ, проверить объявление
  выбранного состояния. Прокрутить и вернуться; выбор сохранён. Достичь общей
  проверки, услышать её недоступность/доступность, результат и ошибки ответа.
- [ ] **Quiz retry/completion:** после проверки состояние редактирования понятно;
  retry очищает попытку предсказуемо, «Завершить проверку» доступна при нужном
  результате. Обновление прогресса после завершения доступно для чтения.
- [ ] **Практикум:** пройти из Home в каталог и кейс, прослушать симптомы,
  предупреждения и условия; вкладки/разделы доступны в логичном порядке.
- [ ] **Диагностическое действие:** найти проверку, выбрать требуемые условия,
  понять выбранное состояние и выполнить действие без визуального угадывания.
- [ ] **Результат измерения / journal:** прочитать значение, единицы, точки,
  условия и ошибки; найти результат в журнале. Порядок фокуса сохраняет связь
  между действием и результатом, длинные записи достижимы прокруткой.
- [ ] **Гипотезы/citations/интерпретация:** состояния выбора объявляются;
  модальное окно выбора evidence доступно, закрытие возвращает фокус;
  нет ловушек фокуса и недостижимых кнопок за длинным содержимым.
- [ ] **Итог практикума:** прочитать PASS/FAIL, балл и объяснения; понять состояние
  сохранения/ошибку записи и действие повторного сохранения, если ошибка реально
  возникла. Ошибки не нужно искусственно вызывать очисткой данных.
- [ ] **Retry/выход:** диалог подтверждения объявляется, cancel/confirm различимы,
  отмена сохраняет текущую попытку; после закрытия фокус не теряется.
- [ ] **Общий проход:** без снятия TalkBack дойти до основных кнопок и вернуться
  назад; повторить критичные места с крупным текстом и в обеих темах по разрешению.
