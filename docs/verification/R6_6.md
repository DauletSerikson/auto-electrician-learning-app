# R6.6 — app smoke confidence

## A. Автоматическая часть

`test/app_smoke_test.dart` запускает реальный AutoElectricianApp и real course
assets. Home → Course → Module → safety_01 → правильный ответ → explicit
completion → Module checkmark → Home 1/22 и следующий урок safety_02.
Повторное создание приложения подтверждает загрузку сохранённого прогресса.
До ответа completion disabled, до записи store пустой, после неё ровно один
completion write. SharedPreferences platform fake из существующей suite
изолирует storage и снимается в teardown. UI/domains/services не заменены.

Выбран app-level widget test: весь требуемый Dart navigation/storage flow
воспроизводится без новой dependency integration_test и без production
architecture changes. Реальные Android lifecycle, launcher, native storage
и системные insets проверяются отдельно на устройстве.
Нет golden/pixel assertions и произвольных длинных задержек. Прокрутка
lazy ListView выполняется через scrollUntilVisible/ensureVisible; короткие
async yields нужны для bundled asset continuations.

Проверки: `dart format lib test`, `flutter analyze` (`No issues found!`),
`flutter test --reporter compact` (600 passed), `git diff --check` (чисто),
`flutter build apk --release` (успешно). Identity и версия в APK проверены.
Production, course JSON, persistence schema и dependencies не изменены.
