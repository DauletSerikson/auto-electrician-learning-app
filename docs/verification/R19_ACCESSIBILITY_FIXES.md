# R19 — Русская локаль и доступный статус уроков

Дата завершения отчёта: 6 ноября 2026, Asia/Qyzylorda.

## Основание и baseline

Владелец отдельно согласовал **оба исправления**, найденные при R19.2B:
русскую локаль со стандартным `flutter_localizations` из SDK и доступный статус
завершения урока. Это отдельный согласованный этап исправлений после QA.

Worktree `electrician-r19`, ветка `fix/r19-release-readiness`, исходный HEAD
`6c4582f163c33414f2517aa2fbcdafc456be3afb`; до начала рабочее дерево чистое.
Изучены `AutoElectricianApp`, `ModuleScreen`, callers/navigation, app smoke,
progress loading tests и реализация Localizations/Semantics в установленном SDK.
Незакоммиченные материалы других worktree не изменялись.

Исходная ручная проба и ограничения описаны в [R19.2B](R19_2B_ANDROID_QA.md):
владелец не понимал русские тексты из-за английского акцента; проба с запросом
ru_RU в настройке Samsung TTS не помогла. Диагностика подтвердила effective
locale en_US у приложения на телефоне с kk-KZ. В списке уроков галочка completion
не имела доступного названия.

## Что изменено

### Локаль интерфейса и semantics

`lib/main.dart` задаёт единственную текущую locale `ru` и стандартные SDK
localization delegates Material/Widgets/Cupertino. Кнопка Back и остальные
стандартные элементы теперь используют русскую локализацию.

Добавлена явная граница `Semantics(localeForSubtree: Locale('ru'))` вокруг
содержимого MaterialApp builder, включая Navigator и все routes. Это необходимо
для языка screen reader: в используемом SDK application-level Localizations
оставляет localeForSubtree=null и содержит TODO о передаче application locale
в engine (`widgets/localizations.dart`). Одна установка locale интерфейса
не является достаточной проверкой языка конечных semantics-узлов.

Здесь не меняется системный язык, TTS engine или голос телефона. Приложение
остаётся русскоязычным offline-first курсом; новый проект мультиязычного контента
и ARB-механизм не вводились. Понятность фактической речи проверяется отдельно
на телефоне, а не объявляется доказанной по widget assertions.

### Статус завершения урока

В `lib/screens/module_screen.dart` визуальный вид списка сохранён. Для ведущей
галочки добавлен semanticLabel «Урок N, завершён», для номера незавершённого
урока — semanticsLabel «Урок N, не завершён». В merged доступном имени строки
сохраняются название, описание и время; заголовок/статус не дублируются.
Действие открытия урока сохраняется. Это представление уже прочитанного прогресса,
не изменение completion правил или данных.

### Зависимости

Добавлены только SDK package `flutter_localizations` и необходимая ему
транзитивная `intl 0.20.3`. `flutter pub get` выполнен. Сравнение каждого прежнего
package entry в lockfile с HEAD подтвердило: **существующие пакеты/версии не изменены**.
Backend, state-management frameworks и другие зависимости не добавлялись.
Версия приложения, applicationId и Android signing configuration не менялись.

## Тесты и воспроизведение

Новый `test/widgets/app_accessibility_test.dart` содержит **5 regression tests**:

- Три platform locale: kk-KZ / en-US / ru. Проверяются effective locale ru,
  русская подсказка «Назад» и **locale конечного semantics node** карточки «Курс»;
  после перехода проверяются русская кнопка и язык её semantics node на новой route.
- Две lesson state: completed/incomplete. Проверяются нужный статус и title
  ровно по одному разу, сохранённое действие tap и отсутствие storage writes.

До изменения production-кода все пять тестов **FAIL** на старых locale/labels.
После исправления отдельный запуск новых tests и app smoke: **6 PASS**.
Технические ошибки первоначального setup тестов исправлены: неверное имя SDK
getter и время освобождения SemanticsHandle. Assertions не удалялись/не ослаблялись.

В существующем `test/app_smoke_test.dart` заменены только два `tester.pageBack()`:
в установленном SDK этот helper жёстко ищет tooltip `Back`. Теперь smoke явно
проверяет единственную кнопку «Назад» и нажимает её. Все прежние assertions
navigation/completion/storage/restart сохранены. Первый полный запуск выявил
именно этот устаревший English locator; он не назван дефектом нового runtime.

### Прослушивание и настройки телефона

После обновления владелец сообщил, что основной русский текст читается правильно,
но начальное название и числа ещё звучат с английским акцентом. С его разрешения
русский голос выбран через системный экран Samsung TTS; TalkBack перезапущен.
Владелец подтвердил понятность речи и выбрал **оставить русский голос**.
Итоговые настройки: Samsung TTS `ru_RU`, язык телефона `kk-KZ` сохранён,
масштаб текста 1.0, ночной режим auto; TalkBack выключен, как до проверки.
Само приложение системные настройки не меняет.

### Оставшийся дефект: лишние числовые объявления общего прогресса

Последующее уточнение владельца отменяет трактовку предыдущего подтверждения как
полного PASS блока «Общий прогресс»: TalkBack по-прежнему произносит лишние
«4 и 0», а после количества уроков — дополнительные непонятные числа.
По наблюдению владельца, эти элементы не видны обычному пользователю.

**Статус: OPEN / исправление отложено по просьбе владельца.** Первопричина
дублирующихся или лишних числовых semantics-объявлений не установлена;
не следует считать её доказанно проблемой голоса Samsung TTS. Следующий отдельный
этап должен сопоставить видимый текст и semantics-дерево блока, воспроизвести
лишние объявления и проверить исправление реальным прослушиванием.
В текущем этапе дополнительных изменений кода по этому замечанию нет.

Итог accessibility-ретеста: **PARTIAL; MANUAL QA REQUIRED**.
Русская локаль и статусы добавлены и проверены автоматикой/нативными метаданными,
понятность основной речи подтверждена владельцем. Блок общего прогресса остаётся
с открытым дефектом; полный чек-лист TalkBack не завершён.

## Scope и ограничения

Production изменения ограничены `lib/main.dart` и
`lib/screens/module_screen.dart`. Также затронуты pubspec/lockfile, новый test,
совместимый locator в app smoke и этот отчёт. Course assets/порядок/ID,
scoring, quiz submit/retry, simulation, diagnostic engine и persistence
не изменялись. Пользовательские данные не очищаются и не мигрируют.

Даже успешное выборочное прослушивание не заменяет весь чек-лист TalkBack,
другие устройства/TTS engines и независимое профильное safety review.
Готовность к выпуску автоматически не меняется на READY. Push, merge, tag и
Release не выполняются.

Изменения этого этапа оставлены незакоммиченными в `electrician-r19`.
Исторический отчёт `docs/verification/R19_2B_ANDROID_QA.md` сохранён без изменений;
этот документ дополняет его результатами согласованных исправлений и ретеста.
Фактический отчёт R19.1 остаётся в другом worktree:
`electrician/docs/verification/R19_TECHNICAL_AUDIT.md` (ранее обнаруженный
незакоммиченный файл). Он и шесть ранее изменённых документов корневого worktree
не перезаписывались. Новые этапы разработки и R19.2B-сценарии не запускались
после просьбы владельца остановиться на отчёте.
